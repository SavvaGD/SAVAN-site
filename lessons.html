Программа обучения

Пошаговый путь от новичка до создания 3D-игр

1. Программирование для начинающих: Ursula

Создаём 3D-миры на движке Godot. Визуальные схемы (ПРИМС) без сложного кода.

2. Создание серьёзных игр на Scratch

Блочное программирование, переменные, циклы, события.

3. Терминальные игры на Python

Создаём текстовые квесты и игры в консоли, изучая синтаксис Python.

4. Продвинутый уровень: C

Погружение в системное программирование. Память и указатели.

5. ПК и мобильные игры на C + Raylib

Создание реальных 2D-игр с графикой на языке C.

6. 3D игры на Unreal Engine

Работа с мощным движком, Blueprints, создание 3D-локаций.
