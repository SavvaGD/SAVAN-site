5.2. Сайт и домен

Хостинг сайта осуществляется бесплатно на платформе GitHub Pages. Это значит, что сайт живет прямо в репозитории с кодом.

Как куплен домен?

Домен savanschool.site был приобретен на российском регистраторе Jino. Чтобы сайт на GitHub Pages открывался по этому красивому адресу, мне пришлось вручную прописывать A-записи и CNAME-записи в DNS-панели.

Отдельная боль — это получение SSL-сертификата (зеленого замочка). GitHub выпускал его с задержкой, и нам пришлось перепробовать кучу способов, чтобы заставить его работать.
